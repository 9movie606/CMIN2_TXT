# Cloudflare Workers 動態隨機優選 IP 訂閱生成器

這是一個完全無伺服器（Serverless）、零外部依賴的動態 IP 訂閱分發系統，基於 **Cloudflare Workers + KV** 構建。

每次訂閱端或瀏覽器讀取主網址時，系統都會即時從每個地區隨機抽取指定數量的不重複 IP（例如每區隨機 5 個），並自動合併該 IP 所屬的所有地區名稱作為節點備註（格式：`IP#地區1-地區2`）。內建密碼保護的網頁管理後台，隨時可在手機或電腦上修改原始節點庫。

---

## ✨ 核心特性

* **即時真隨機抽取**：每次請求都會使用 Fisher-Yates 洗牌演算法，從各個地區分類中隨機抽取固定數量且全局不重複的 IP。
* **多地區自動合併備註**：若同一個 IP 同時存在於多個地區，輸出時會自動合併標註為 `IP#地區1-地區2-...`。
* **內建網頁管理後台 (`/admin`)**：無需重新部署程式碼，透過密碼驗證即可直接在網頁端讀取、編輯並寫入 KV 資料庫。
* **極致省流快取策略**：主訂閱介面讀取 KV 時設有 1 小時（3600 秒）邊緣快取，大幅節省 Cloudflare 免費版 KV 讀取額度；同時確保每次刷新仍輸出全新隨機組合。
* **高度可自訂參數**：支援透過環境變數隨時調整「每區抽取數量」與「首行公告備註」。

## 🚀 部署教學

### 第一步：建立 KV 命名空間
1. 登入 [Cloudflare Dashboard](https://cloudflare.com)。
2. 在左側選單點擊 **Workers & Pages** → **KV**。
3. 點擊 **Create a namespace**，名稱可填寫 `IP_SUB_KV`（或任意名稱），點擊建立。

### 第二步：建立 Worker 並部署程式碼
1. 回到 **Workers & Pages** → 點擊 **Create** → **Create Worker**。
2. 為 Worker 命名（例如 `cmin2-sub`），點擊 **Deploy**。
3. 點擊右上角的 **Edit code**，清空預設程式碼，將本倉庫的 `worker.js` 完整貼入，再次點擊 **Deploy**。

### 第三步：綁定 KV 與設定環境變數（關鍵步驟）
進入該 Worker 的 **Settings（設定）** 頁面完成以下配置：

#### 1. 綁定 KV 命名空間
在 **Bindings（綁定）** 區塊點擊 **Add** → 選擇 **KV Namespace**：
* **Variable name（變數名稱）**：必須填寫 `IP_KV`（全大寫）
* **KV namespace**：選擇第一步建立的命名空間

#### 2. 設定環境變數
在 **Variables and Secrets（變數與機密）** 區塊新增以下變數：

| 變數名稱 | 必填 | 說明與範例 |
| :--- | :---: | :--- |
| `ADMIN_PASSWORD` | **是** | 後台 `/admin` 的登入與寫入密碼（建議點選 Encrypt 加密保存） |
| `PER_REGION_COUNT` | 否 | 每個地區隨機抽取的 IP 數量，預設為 `5` |
| `HEADER_NOTE` | 否 | 訂閱列表第一行的公告備註（若留空則不顯示首行） |

> **💡 `HEADER_NOTE` 格式建議**：  
> 若需配合第三方優選訂閱生成器使用，建議採用「真實 IP + 備註」格式，且備註中避免出現半形逗號 `,` 或空格，以免解析器中斷。  
> 範例：`1.1.1.1#移動專用CMIN2-不在下列地區請使用備用訂閱`

*(設定完成後，建議回到程式碼頁面確認已儲存並部署最新設定。)*

### 第四步：綁定自訂網域
由於部分地區網路環境無法直接連線預設的 `*.workers.dev` 網域，強烈建議綁定自己的網域：
1. 進入 Worker 的 **Settings** → **Domains & Routes**。
2. 點擊 **Add** → **Custom Domain**，輸入你的子網域（例如 `://example.com`）並確認生效。

## 📖 使用說明

### 1. 初始化與編輯 IP 列表
1. 瀏覽器開啟：`https://你的網域/admin`
2. 輸入你在環境變數中設定的 `ADMIN_PASSWORD`。
3. 依照以下格式貼入原始 IP 列表（地區名稱單獨一行，下方緊跟該地區的 IP），點擊 **「保存寫入 KV」**：

```text
上海
104.16.4.14
104.16.130.3

北京
104.16.4.14
104.17.78.30

廣東
23.227.38.65
104.16.4.14
```

### 2. 獲取隨機訂閱連結
直接存取以下任一網址，即可取得純文本（`text/plain`）格式的隨機優選列表，可貼入各類優選訂閱生成器或支援純文本節點的客戶端中使用：
* 主入口：`https://你的網域/`
* 相容路徑：`https://你的網域/all_list.txt`

> **⚠️ 關於快取延遲提醒**：  
> 為了節省 KV 讀取次數，主訂閱網址讀取 KV 原始資料時設有 **1 小時（3600 秒）快取**。在 `/admin` 修改並保存新列表後，後台可立即讀到最新內容，而主訂閱網址最遲會在 1 小時內全網同步更新。

## 📊 免費額度參考
本專案完全相容 Cloudflare 免費方案（每日重置額度）：
* **Worker 請求數**：100,000 次 / 天
* **KV 讀取次數**：100,000 次 / 天（搭配 1 小時邊緣快取極難觸及上限）
* **KV 寫入次數**：1,000 次 / 天
